# My Personal Portfolio

## About the Project
This is my personal portfolio website created using HTML and CSS. It introduces me, displays my technical skills, shows my projects, and provides a contact form.

## Features
- Home section
- About Me section
- Technical Skills table
- My Projects section
- Contact form
- Back to Top button
- Responsive design for mobile devices

## Technologies Used
- HTML5
- CSS3

## Project Structure
```text
My-Portfolio/
│
├── index.html
├── style.css
├── README.md
│
└── images/
    └── profile.jpg
```

## How to Run
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Explore the portfolio website.
